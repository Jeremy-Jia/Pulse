Pulse 1.3.0 外观配置验证
2026-10-17 · Asia/Shanghai

功能
- 悬浮窗可选择无边框，保留背景、拖动、所选指标与现有留白。
- 桌面小部件可分别配置名称颜色、数值颜色、背景颜色，提供预设色及 6 位 RGB 输入。
- 小部件背景支持 0–100% 不透明度，结合独立无边框选项可仅显示文字。
- 支持实时样式预览与恢复默认。小部件配色独立于悬浮窗；未自选数值色时跟随主题。
- 小部件外观配置应用于所有 Pulse 小部件；指标、字号、粗体和密度继续共用。
- Root、ADB 和普通权限数据读取逻辑、原生基准代码与 Android 权限列表均未改动。

验证
- 小米 18 系列 / Android 17 非 Root 实机安装成功，versionCode 4，versionName 1.3.0。
- assembleDebug、assembleDebugAndroidTest、lintDebug 通过：0 errors，23 warnings。
- RemoteViews 经 Parcel 往返后，在 AppWidgetHostView 中实际渲染配色、透明度和边框。
- 白底深色名称/蓝色数值、深色半透明背景、全透明背景均通过像素及文字颜色检查。
- 悬浮窗在真实 WindowManager 窗口中验证有/无描边像素。
- 恢复默认、主题跟随、旧版集合工厂的颜色、设置页入口均通过。
- 颜色对话框非法输入保持打开并提示；合法输入应用；取消不应用。
- 使用隔离的测试偏好；原用户配置经测试内对比和测试外 XML 语义对比均确认未改变。
- 未在用户桌面分配或添加小部件；已有宿主与 Android 8–11 的完整系统回归沿用各自验证边界。
- 本次未连接 Root 小米 15 做实机回归。

使用
Pulse → 悬浮窗 → 显示与交互 → 无边框。
Pulse → 悬浮窗 → 桌面小部件 → 名称颜色 / 数值颜色 / 背景颜色 / 背景不透明度 / 小部件无边框。
